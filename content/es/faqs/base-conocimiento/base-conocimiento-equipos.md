---
title: "Base de Conocimiento para Equipos y Agencias"
description: "Cómo los equipos y agencias usan la base de conocimiento para mantener la coherencia del contenido en múltiples personas, clientes y proyectos."
faq:
  - q: "¿Cómo comparte un equipo la misma base de conocimiento?"
    a:
      - "Todo el equipo con acceso al proyecto usa la misma base automáticamente. Cuando un miembro sube un nuevo documento, todos los demás crean contenido fundamentado en esa información actualizada. La consistencia factual es automática."

  - q: "¿Cómo gestionan las agencias bases de conocimiento de múltiples clientes?"
    a:
      - "Cada proyecto de cliente tiene su propia base de conocimiento aislada. La información del cliente A nunca se mezcla con la del cliente B. Los miembros del equipo asignados a cada cliente acceden solo a la base de su proyecto."

  - q: "¿Cómo incorporo a un nuevo miembro del equipo usando la base de conocimiento?"
    a:
      - "No necesitas formación especial. El nuevo miembro crea contenido a través del agente de Bazam.ai, que automáticamente usa la base de conocimiento del proyecto. El contexto de marca está en la plataforma, no en la cabeza de nadie — los nuevos miembros producen contenido informado desde el primer día."

  - q: "¿Cómo mantengo la base de conocimiento actualizada en un equipo grande?"
    a:
      - "Asigna un responsable de la base de conocimiento que suba documentos nuevos y elimine los obsoletos periódicamente. En agencias, cada gestor de cuentas mantiene la base de sus clientes. La revisión trimestral mantiene la información fresca."

  - q: "¿Puede cada miembro del equipo subir documentos a la base de conocimiento?"
    a:
      - "Depende de los permisos configurados. Los administradores y editores gestionan la base de conocimiento. Los colaboradores crean contenido usando la base existente. Esto evita que documentos no verificados afecten la calidad del contenido."

  - q: "¿Cómo uso la base de conocimiento para incorporar nuevos clientes de agencia?"
    a:
      - "Pide al nuevo cliente sus materiales clave: presentación corporativa, fichas de producto, FAQ y ejemplos de comunicación. Sube todo al proyecto del cliente en Bazam.ai. El agente puede crear contenido alineado con el cliente desde la primera sesión."

  - q: "¿Cómo evito que información confidencial de un cliente llegue al contenido de otro?"
    a:
      - "Los proyectos aislados de Bazam.ai garantizan que la base de conocimiento de cada cliente es completamente independiente. El agente nunca cruza referencias entre proyectos. La confidencialidad está garantizada a nivel de arquitectura."

  - q: "¿Puedo tener diferentes bases de conocimiento para diferentes campañas?"
    a:
      - "Una base por proyecto. Si necesitas bases separadas para campañas muy diferentes, crea proyectos separados. Lo más habitual es mantener una base completa por marca y usar el contexto de cada asistente para dirigir qué información es relevante."

  - q: "¿Cómo mido si mi base de conocimiento es suficientemente completa?"
    a:
      - "Si el contenido que produce la IA necesita pocos ajustes factuales, la base es buena. Si constantemente corriges datos, especificaciones o afirmaciones, necesitas subir más documentación. La calidad del output refleja la calidad del input."

  - q: "¿Qué pasa con la base de conocimiento si cancelo mi cuenta?"
    a:
      - "Es tu información. Los documentos subidos se pueden descargar antes de cancelar. Bazam.ai no retiene tu base de conocimiento después de la cancelación de la cuenta."
