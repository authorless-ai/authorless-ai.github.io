---
title: "Privacidad de la Base de Conocimiento"
description: "Cómo Bazam.ai protege la privacidad y seguridad de tu base de conocimiento y documentos empresariales."
faq:
  - q: "¿Mis documentos están seguros en Bazam.ai?"
    a:
      - "Sí. Los documentos se almacenan de forma segura y se usan exclusivamente para crear contenido en tu proyecto. No se comparten entre proyectos ni se usan para entrenar modelos."
  - q: "¿Quién puede acceder a mi base de conocimiento?"
    a:
      - "Solo los miembros de tu proyecto con los permisos adecuados. Los administradores controlan quién tiene acceso. Proyectos diferentes no pueden ver los datos de otros."
  - q: "¿La IA de Bazam.ai se entrena con mis documentos?"
    a:
      - "No. Tus documentos se usan en tiempo real para crear contenido, pero no se utilizan para entrenar los modelos de IA. Tu información es tuya."
  - q: "¿Puedo eliminar mis documentos?"
    a:
      - "Sí — elimina cualquier documento en cualquier momento. La eliminación es definitiva. El contenido ya creado no se afecta, pero la IA deja de usar ese contexto."
  - q: "¿Qué pasa con mis datos si cancelo mi suscripción?"
    a:
      - "Tus datos quedan accesibles hasta el final del periodo de facturación. Después, se eliminan de los sistemas de Bazam.ai. Descarga tu contenido antes de cancelar."
  - q: "¿Es seguro subir información comercial sensible?"
    a:
      - "Bazam.ai trata los documentos con confidencialidad. No obstante, no subas información extremadamente sensible como contraseñas, datos financieros detallados o información personalísima."
  - q: "¿Bazam.ai cumple con el RGPD?"
    a:
      - "Sí — los datos se procesan conforme al Reglamento General de Protección de Datos. La información personal que subas se trata con las protecciones que exige la legislación europea."
  - q: "¿Puedo controlar qué miembros ven qué documentos?"
    a:
      - "Los miembros del proyecto ven la base de conocimiento del proyecto. Para separar información, usa proyectos diferentes con permisos independientes."
  - q: "¿Los documentos se comparten entre proyectos?"
    a:
      - "No — cada proyecto tiene su propia base independiente. Si gestionas múltiples marcas, cada una tiene su propia base aislada."
  - q: "¿Cómo exporto mi base de conocimiento?"
    a:
      - "Tus documentos originales son siempre tuyos. Descárgalos cuando lo necesites. El contenido creado con Bazam.ai también es de tu propiedad."
