faq:
  - q: "¿Cómo optimizo mis fichas de producto para SEO?"
    a:
      - "Títulos descriptivos con palabras clave, descripciones únicas y detalladas, imágenes con alt text optimizado. Bazam.ai crea descripciones de producto optimizadas para SEO — cada ficha es única y relevante para buscadores."
  - q: "¿Las descripciones de producto generadas por IA posicionan bien?"
    a:
      - "Sí — cuando son únicas y detalladas. Bazam.ai crea descripciones originales para cada producto desde tu base de conocimiento. Descripciones únicas posicionan; descripciones copiadas del fabricante no."
  - q: "¿Cómo posiciono mis páginas de categoría?"
    a:
      - "Con contenido introductorio de calidad que incluya palabras clave relevantes. Bazam.ai crea textos de categoría optimizados que ayudan tanto al SEO como a los compradores."
  - q: "¿Debería crear un blog para mi tienda online?"
    a:
      - "Sí — las guías de compra y comparativas posicionan para búsquedas informacionales que preceden a la compra. Bazam.ai crea este contenido de blog orientado a la conversión."
  - q: "¿Cómo compito con Amazon en los buscadores?"
    a:
      - "Con contenido de cola larga y especializado. Amazon domina las búsquedas genéricas; tú ganas las específicas. 'Mejor silla ergonómica para programadores bajo 300 €' — Bazam.ai crea este contenido de nicho."
  - q: "¿Cómo uso las reseñas de producto para SEO?"
    a:
      - "Las reseñas añaden contenido único y relevante a tus fichas de producto. Incentiva las reseñas y marca los datos estructurados para rich snippets. Las estrellas en los resultados de búsqueda aumentan el CTR."
  - q: "¿Cómo creo contenido para búsquedas comerciales?"
    a:
      - "Guías de compra, comparativas y 'mejores X de 2025.' Bazam.ai crea este contenido que captura compradores en la fase de investigación — justo antes de decidir dónde comprar."
  - q: "¿Cómo optimizo la velocidad de carga para SEO?"
    a:
      - "Esto es técnico, no de contenido. Bazam.ai crea el contenido optimizado; tu desarrollador o plataforma optimiza la velocidad. Ambos factores importan para el posicionamiento."
  - q: "¿Debería crear landing pages específicas para productos?"
    a:
      - "Sí para productos principales. Landing pages con contenido persuasivo convierten mejor que fichas de producto genéricas. El asistente de copywriting de Bazam.ai crea landing pages de producto."
  - q: "¿Cómo uso los datos de búsqueda para crear contenido de producto?"
    a:
      - "Analiza qué buscan los compradores con Google Search Console y herramientas de keywords. Bazam.ai crea contenido que responde estas búsquedas — cada post es un punto de entrada para un comprador potencial."
