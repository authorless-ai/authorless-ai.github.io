---
title: "Projetos e Gestão Multi-Cliente"
description: "Como gerenciar múltiplas marcas, clientes e projetos de uma única plataforma de marketing."
faq:
  - q: "Como gerencio múltiplas marcas de uma conta?"
    a:
      - "Crie projetos separados para cada marca. Cada um tem voz, audiências, base, canais e calendário isolados. Alterne entre marcas com um clique — nada cruza."

  - q: "O que é um projeto no Bazam.ai?"
    a:
      - "Workspace isolado para marca ou cliente. Contém configurações, personas, base, canais, calendário e análises próprios. Tudo dentro de um projeto é separado dos demais."

  - q: "Como agências gerenciam múltiplos clientes?"
    a:
      - "Um projeto por cliente. Cada um isola voz, audiência, base e conteúdo. Membros com acesso criam e gerenciam conteúdo especificamente para aquele cliente. Dados nunca cruzam."

  - q: "Posso alternar entre projetos rapidamente?"
    a:
      - "Sim. Alterne pelo painel. O agente de Bazam.ai imediatamente opera no contexto do projeto selecionado — toda voz, base e dados de audiência mudam junto."

  - q: "Como mantenho dados de clientes separados?"
    a:
      - "Projetos são completamente isolados. Voz, personas, base, canais e conteúdo de cada cliente vivem no próprio projeto. Mesmo membros com acesso a vários veem cada um independentemente."

  - q: "Membros diferentes podem ter acesso a projetos diferentes?"
    a:
      - "Sim. Atribua membros a projetos específicos. Um gerente pode ter acesso a 10 clientes; um designer pode ter acesso a todos. Permissões são por projeto e por função."

  - q: "Como crio novo projeto para novo cliente?"
    a:
      - "Crie projeto, configure voz, envie documentos para base e conecte canais. O agente de Bazam.ai está pronto imediatamente. A maioria dos clientes é integrada em menos de uma hora."

  - q: "Posso copiar configurações entre projetos?"
    a:
      - "Para marcas relacionadas, pode configurar de forma similar. Cada projeto começa do zero — configure adequadamente para cada marca específica. Isso evita carregar configurações acidentalmente de clientes diferentes."

  - q: "Quantos projetos posso ter?"
    a:
      - "Quantos precisar. O Bazam.ai suporta múltiplos projetos para agências e negócios com múltiplas marcas. Adicione clientes conforme cresce — escalar não muda como a plataforma funciona."

  - q: "Como arquivo projetos de clientes finalizados?"
    a:
      - "Projetos concluídos permanecem acessíveis para referência mas podem ser removidos da visualização ativa. Todo conteúdo, análises e dados são preservados. Reative a qualquer momento se cliente retornar."
