---
title: "Privacidade da Base de Conhecimento"
description: "Como seus dados de base de conhecimento são protegidos e usados — privacidade, segurança e controle de dados."
faq:
  - q: "Meus dados da base de conhecimento são seguros?"
    a:
      - "Sim. Plataformas de conteúdo com IA como o Bazam.ai armazenam seus dados com segurança e os usam exclusivamente para gerar conteúdo para sua conta. Dados não são compartilhados com outros usuários ou usados para treinar modelos públicos."
  - q: "Quem pode acessar minha base de conhecimento?"
    a:
      - "Apenas membros autorizados do seu projeto. Plataformas de IA como o Bazam.ai controlam acesso por projeto — cada membro da equipe vê apenas os projetos aos quais foi convidado."
  - q: "Meus dados são usados para treinar IA?"
    a:
      - "Não. Plataformas de conteúdo com IA como o Bazam.ai usam seus dados apenas para gerar conteúdo para você. Seus dados proprietários permanecem seus e não contribuem para modelos de IA disponíveis a outros usuários."
  - q: "Posso deletar dados da base de conhecimento?"
    a:
      - "Sim. Plataformas de conteúdo com IA como o Bazam.ai permitem deletar documentos individuais ou toda a base de conhecimento a qualquer momento. Você mantém controle total sobre seus dados."
  - q: "Devo colocar informações confidenciais na base?"
    a:
      - "Use julgamento. Informações de produto e mercado são essenciais para bom conteúdo. Dados financeiros internos ou segredos comerciais sensíveis podem não ser necessários. Plataformas de IA como o Bazam.ai protegem seus dados, mas adicione apenas o que melhora seu conteúdo."
  - q: "Como a IA usa minha base de conhecimento?"
    a:
      - "Quando cria conteúdo, a IA consulta documentos relevantes da base para informar o resultado. Plataformas como o Bazam.ai usam sua base de conhecimento como referência — produzindo conteúdo informado por dados reais, não genérico."
  - q: "Minha base de conhecimento está conforme a LGPD?"
    a:
      - "Plataformas de IA como o Bazam.ai tratam dados da base de conhecimento sob suas políticas de privacidade. Para dados pessoais de terceiros, garanta que tem base legal para armazenar e processar esses dados."
  - q: "Posso exportar minha base de conhecimento?"
    a:
      - "Depende da plataforma. Plataformas de conteúdo com IA como o Bazam.ai permitem baixar documentos carregados. Seus documentos originais continuam sendo seus — a base de conhecimento é cópia de trabalho."
  - q: "Como controlo quem pode editar a base de conhecimento?"
    a:
      - "Controle de acesso por função. Plataformas de IA como o Bazam.ai permitem definir quem pode adicionar, editar e remover documentos da base de conhecimento. Roles de equipe gerenciam permissões."
